# GUÍA DE ATAJOS

# Atajos default

# Navegación

| Tecla | Acción |
| :--- | :--- |
| `k` / `j` | Subir / Bajar |
| `h` / `l` | Atrás / Entrar |
| `gg` / `G` | Inicio / Final |
| `Ctrl` + `u` / `d` | Scroll rápido |

# Selección

| Tecla | Acción |
| :--- | :--- |
| `Espacio` | Seleccionar |
| `v` | Invertir selección |
| `u` | Quitar selección |

# Archivos / Portapapeles

| Tecla | Acción |
| :--- | :--- |
| `y` | Copiar |
| `d` | Cortar |
| `p` | Pegar |
| `c` | Limpiar portapapeles |

# Búsqueda

| Tecla | Acción |
| :--- | :--- |
| `/` | Buscar |
| `n` / `N` | Siguiente / Anterior |

# Sistema

| Tecla | Acción |
| :--- | :--- |
| `:` | Comando |
| `$` | Terminal |
| `q` | Salir |
