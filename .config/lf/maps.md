# GUÍA DE ATAJOS

──────────────────────────────────────────
## Atajos default

──────────────────────────────────────────
### Navegación
  k / j             Subir / Bajar
  h / l             Atrás / Entrar
  gg / G            Inicio / Final
  Ctrl+u / d        Scroll rápido

──────────────────────────────────────────
### Selección
  Espacio           Seleccionar
  v                 Invertir selección
  u                 Quitar selección

──────────────────────────────────────────
### Archivos / Portapapeles
  y                 Copiar
  d                 Cortar
  p                 Pegar
  c                 Limpiar portapapeles
  Del               Borrar archivo

──────────────────────────────────────────
### Búsqueda
  /                 Buscar
  n / N             Siguiente / Anterior

──────────────────────────────────────────
### Sistema
  :                 Comando
  $                 Terminal
  q                 Salir

──────────────────────────────────────────
## Atajos personalizados

──────────────────────────────────────────

  ?                 Ayuda
