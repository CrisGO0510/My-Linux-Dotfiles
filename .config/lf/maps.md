# GUÍA DE ATAJOS

──────────────────────────────────────────
## Atajos default

──────────────────────────────────────────
### Navegación
  k / j             Subir / Bajar
  h / l             Atrás / Entrar
  gg / G            Inicio / Final
  Ctrl+u / d        Scroll rápido

──────────────────────────────────────────
### Selección
  Espacio           Seleccionar
  v                 Invertir selección
  u                 Quitar selección

──────────────────────────────────────────
### Archivos / Portapapeles
  y                 Copiar
  d                 Cortar
  p                 Pegar
  c                 Limpiar portapapeles

──────────────────────────────────────────
### Búsqueda
  /                 Buscar
  n / N             Siguiente / Anterior

──────────────────────────────────────────
### Sistema
  :                 Comando
  $                 Terminal
  q                 Salir

──────────────────────────────────────────
## Atajos personalizados

──────────────────────────────────────────
### Terminales
  t                 Terminal Externa
  T                 Terminal Interna

──────────────────────────────────────────
### Archivos / Portapapeles
  x               Comprimir archivos
  D               Borrar archivos

──────────────────────────────────────────
### Ayuda
  ?                 Mostrar esta guía
